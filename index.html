¿Qué es CSS?

CSS, o Cascading Style Sheets, es un lenguaje utilizado para definir la presentación y el diseño de una página web. Permite controlar colores, tamaños, espacios, bordes, fuentes y la distribución de los elementos.

La utilización de CSS permite separar el contenido de una página web de su presentación visual, facilitando el mantenimiento y la organización del sitio.

Características de CSS

  • Permite cambiar colores y fuentes.
  • Controla márgenes y espacios internos.
  • Permite crear diseños responsivos.
  • Facilita la organización visual del contenido.
  • Permite aplicar estilos de manera selectiva.

Tipos de selectores utilizados

Selector de elemento

Se utiliza directamente con elementos HTML, como h1, p, body o section.

Selector de clase

Se identifica utilizando un punto, por ejemplo: .tarjeta o .subtitulo.

Selector de ID

Se identifica utilizando el símbolo #, por ejemplo: #encabezado o #css.

Modelo de caja

Cada elemento HTML puede representarse mediante un modelo de caja compuesto por contenido, padding, borde y margen.
