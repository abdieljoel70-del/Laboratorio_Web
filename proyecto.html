Proyecto destacado

Plataforma Web de Seguridad

Diseño ficticio de una plataforma web enfocada en la administración de información relacionada con seguridad informática.

Descripción

El proyecto consiste en desarrollar una plataforma responsiva que permita presentar información de seguridad de forma organizada.

La interfaz utiliza HTML5, CSS y Bootstrap para proporcionar una experiencia consistente en computadoras, tabletas y teléfonos móviles.

Tecnologías utilizadas

  • HTML5
  • CSS3
  • Bootstrap
  • JavaScript
  • Visual Studio Code

Objetivos

Seguridad

Presentar información de manera organizada y segura.

Accesibilidad

Crear una interfaz fácil de utilizar.

Responsividad

Adaptar el sitio a distintos dispositivos.
