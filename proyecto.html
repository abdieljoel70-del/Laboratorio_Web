Sitio Web Responsivo

Este proyecto consiste en el desarrollo de un sitio web utilizando HTML5, CSS3 y Bootstrap. El propósito principal es demostrar el uso de estructuras semánticas, estilos, componentes de un framework CSS y diseño responsivo.

Objetivos

  • Crear una estructura organizada utilizando HTML5.
  • Aplicar estilos mediante CSS.
  • Integrar Bootstrap en el desarrollo.
  • Utilizar selectores de elementos, clases e identificadores.
  • Aplicar el modelo de caja de CSS.
  • Crear un diseño adaptable a diferentes tamaños de pantalla.

Tecnologías utilizadas

  • HTML5
  • CSS3
  • Bootstrap
  • Visual Studio Code
  • Navegador web
  • GitHub

Diseño responsivo

El sitio utiliza el sistema de columnas de Bootstrap y reglas CSS mediante media queries. De esta manera, el contenido puede reorganizarse dependiendo del tamaño de pantalla utilizado por el visitante.

Modelo de caja

El modelo de caja se aplica mediante propiedades como margin, border, padding y width. Estas propiedades permiten controlar el espacio exterior, los bordes, el espacio interno y las dimensiones de los elementos.
