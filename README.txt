LABORATORIO DE DESARROLLO WEB - HTML5

Nombre: Abdiel Abreu

DESCRIPCIÓN

Este proyecto fue desarrollado como parte del laboratorio de desarrollo web. El objetivo principal es demostrar el uso de la estructura básica de HTML, la semántica de HTML5 y algunas de las características incorporadas en HTML5.

TECNOLOGÍAS UTILIZADAS

* HTML5
* CSS
* Visual Studio
* Navegador web
* GitHub

ELEMENTOS HTML UTILIZADOS

En el proyecto se utilizaron elementos como:

* html
* head
* body
* h1
* h2
* h3
* p
* ul
* ol
* li
* a
* img

ELEMENTOS SEMÁNTICOS HTML5

También se utilizaron elementos semánticos como:

* header
* nav
* main
* section
* article
* figure
* figcaption
* footer

CARACTERÍSTICAS HTML5

El proyecto incluye ejemplos de características de HTML5 como:

* Video
* Audio
* Canvas
* Elementos semánticos
* Figura y descripción de figura
* Diseño adaptable para diferentes tamaños de pantalla

CSS

El archivo styles.css contiene los estilos utilizados para organizar y presentar visualmente la página web.

CONCLUSIÓN

La realización de este laboratorio permitió practicar la estructura básica de HTML, el uso de elementos y atributos, la semántica de HTML5 y algunas de las funciones multimedia disponibles en HTML5. También permitió utilizar Visual Studio, un navegador web y GitHub como herramientas para desarrollar, visualizar y almacenar el proyecto.
